# ТЕХНІЧНЕ ЗАВДАННЯ (ТЗ)
## На розробку інтерактивного веб-застосунку «Ретро-Аркади XX століття»

---

### 1. ЗАГАЛЬНІ ВІДОМОСТІ

* **Назва проєкту:** «Ретро-Аркади XX століття» (Retro Arcades of the 20th Century).
* **Мова інтерфейсу та контенту:** Українська (100% локалізація).
* **Тип проєкту:** Односторінковий веб-застосунок (SPA — Single Page Application) із клієнтською маршрутизацією на базі **React**.
* **Цільова аудиторія:** Учні, вчителі інформатики, студенти, поціновувачі історії комп'ютерних технологій та ретро-геймінгу.
* **Мета проєкту:** Створити інтерактивний цифровий музей відеоігор другої половини XX століття, реалізований як сучасний React SPA. Кожна гра має власний маршрут (URL), містить інтерактивний аркадний автомат на базі HTML5 Canvas, детальний історичний огляд, технічні факти та систему збереження рекордів.
* **Перелік ігор у колекції:**
  1. **Pong (1972)** — точка відліку комерційної індустрії аркадних автоматів.
  2. **Space Invaders (1978)** — родоначальник жанру Shoot 'em up.
  3. **Pac-Man (1980)** — ікона поп-культури та золотий стандарт лабіринтних аркад.
  4. **Tetris (1984)** — легендарна логічна головоломка століття.
  5. **Snake (1997)** — еталон раннього мобільного геймінгу на монохромних дисплеях.

---

### 2. СТЕК ТЕХНОЛОГІЙ ТА АРХІТЕКТУРА

* **Архітектурний патерн:** SPA (Single Page Application) з компонентним підходом React.
* **Ключові технології:**
  * **React 18+:** Декларативний інтерфейс, хуки стану (`useState`, `useEffect`, `useRef`, `useCallback`, `useContext`).
  * **Клієнтський роутінг:** `react-router-dom` (або сумісний легкий хеш/стан роутер для максимальної портативності без конфігурації веб-сервера).
  * **Стилізація:** Tailwind CSS (utility-first підхід, гнучка сітка, неонові та ретровейв-класи).
  * **Ігрове ядро:** HTML5 Canvas API, вбудований у React-компоненти через `useRef` та керований через `requestAnimationFrame`.
  * **Шрифти:** Google Fonts (`Press Start 2P`, `VT323`, `Rajdhani`).
  * **Звуковий рушій:** Власний аудіо-модуль на базі Web Audio API (генерація частот осциляторами без важких зовнішніх mp3-файлів).
  * **Збереження стану:** Web Storage API (`localStorage`) для фіксації рекордів та глобальних налаштувань (звук, CRT-фільтр).

### 4. ДИЗАЙН-СИСТЕМА ТА UI/UX

#### 4.1. Візуальна стилістика
* **Естетика:** Кіберпанк / Неоновий ретровейв 80-х / Зал аркадних автоматів.
* **Кольорова палітра:**
  * Основне тло: темна ніч (`#05070f`, `#090d1a`).
  * Неоновий маджента / Pink: `#ff2a85`.
  * Неоновий бірюзовий / Cyan: `#00f3ff`.
  * Золотистий бурштин / Amber: `#ffe600`.
  * Монохромний зелений / Terminal: `#39ff14`.
* **CRT Ефект:** Глобальний шар зі сканлініями (Scanlines) та легким мерехтінням люмінофора, який можна перемикати однією кнопкою в шапці (`CRT: УВІМК/ВИМК`).

#### 4.2. Спільні компоненти інтерфейсу
1. **`Navbar`:**
   * Логотип «Ретро-Аркади XX століття» з посиланням на головну сторінку.
   * Меню швидкого переходу між усіма 5 іграми (`NavLink` з підсвічуванням активного маршруту).
   * Інтерактивні кнопки: тумблер аудіо (🔊/🔇) та тумблер CRT (📺).
2. **`ArcadeCabinet` (Універсальний каркас гри):**
   * Корпус аркадного автомата зі скошеними неоновими кутами.
   * Верхнє табло з поточним рахунком та рекордом гри (`High Score`).
   * Canvas-контейнер з оверлеєм старту/паузи/завершення гри.
   * Блок віртуальних кнопок (D-Pad та кнопки дій) для повноцінної гри зі смартфонів.
3. **`GameArticle` (Історико-технічний лекторій):**
   * Блок структурованого матеріалу під грою: біографія творців, передумови створення, технічні обмеження заліза того часу, цікаві історичні факти.
   * Кнопки навігації «← Попередня гра» та «Наступна гра →» безпосередньо внизу статті.
4. **`Footer`:** Інформаційна плашка про навчальний шкільний проєкт, рік розробки та авторство.

### 5. ТЕХНІЧНІ ВИМОГИ ДО ІГРОВИХ МОДУЛІВ

Кожна гра реалізується як ізольований Canvas-рушій всередині React-компонента з життєвим циклом очищення анімації (`cancelAnimationFrame` при розмонтуванні сторінки/зміні роуту):

#### 5.1. Pong (1972) — маршрут `/games/pong`
* **Ігровий процес:** Матч до 5 очок між гравцем (ліва ракетка) та комп'ютерним суперником (права ракетка).
* **Алгоритм:** Розрахунок фізики відскоку м'яча залежно від точки торкання ракетки, поступове наростання швидкості м'яча.
* **Керування:** Клавіші `W`/`S`, стрілки `Вгору`/`Вниз` або сенсорний D-Pad.

#### 5.2. Space Invaders (1978) — маршрут `/games/invaders`
* **Ігровий процес:** Оборона бази від шеренги ворожих космічних кораблів.
* **Алгоритм:** Хвилеподібний рух прибульців «зліва-направо-вниз», динамічне прискорення зі зменшенням їх кількості, випадкові бомбардування гравця.
* **Керування:** Стрілки `Вліво`/`Вправо` (`A`/`D`) + кнопка `Пробіл` / віртуальна кнопка «ВОГОНЬ».

#### 5.3. Pac-Man (1980) — маршрут `/games/pacman`
* **Ігровий процес:** Збір крапок у неоновому лабіринті з униканням зіткнення з привидами.
* **Алгоритм:** Тайлова сітка зі стінами, анімація розкривання рота героя під час руху, примітивний алгоритм патрулювання для привидів.
* **Керування:** 4 напрямки руху (стрілки, `WASD`, екранний хрестик).

#### 5.4. Tetris (1984) — маршрут `/games/tetris`
* **Ігровий процес:** Укладання геометричних фігур тетраміно у прямокутний стакан $10 \times 20$ клітинок.
* **Алгоритм:** 7 стандартних фігур (I, J, L, O, S, T, Z), обертання матриці на $90^\circ$, виявлення та спалювання заповнених рядів, зростання рівня складності.
* **Керування:** `Вліво`/`Вправо` (зсув), `Вниз` (прискорене падіння), `Вгору` / `Пробіл` (поворот фігури).

#### 5.5. Snake (1997) — маршрут `/games/snake`
* **Ігровий процес:** Керування змійкою в замкненому просторі зі стилізацією під зелений LCD-екран ранніх телефонів.
* **Алгоритм:** Черга координат тіла змійки, генерація їжі, перевірка колізій із власним хвостом та стінами, розгін швидкості.
* **Керування:** 4 кнопки напрямку.

### 6. СИСТЕМА ЗВУКУ ТА РЕКОРДІВ

1. **Синтезатор звуку (Web Audio API):**
   * Створюється як React-сервіс або хук `useRetroAudio()`.
   * Синтезує 8-бітні тони в реальному часі (звуки відскоку, поїдання крапок, вибуху прибульців, знищення ліній у Тетрісі).
   * Стан увімкнення звуку глобальний для всіх роутів і запам'ятовується в `localStorage`.
2. **Таблиця рекордів:**
   * Збереження найкращих результатів за ключами:
     * `retro_arcade_score_pong`
     * `retro_arcade_score_invaders`
     * `retro_arcade_score_pacman`
     * `retro_arcade_score_tetris`
     * `retro_arcade_score_snake`
   * На кожній сторінці гри відображається її поточний рекорд, а на головній сторінці (`/`) доступне зведене табло чемпіонів із кнопкою скидання.

### 7. СТРУКТУРА ВИХІДНОГО КОДУ ПРОЄКТУ (REACT)

```text
src/
├── assets/                 # Іконки та декоративні елементи
├── components/             # Перевикористовувані компоненти
│   ├── Navbar.jsx          # Меню навігації з роутами та тумблерами
│   ├── Footer.jsx          # Підвал сайту
│   ├── ArcadeCabinet.jsx   # Оболонка ігрового автомата з кнопками керування
│   └── HighScoresTable.jsx # Компонент зведеної таблиці рекордів
├── games/                  # Ігрові рушії на Canvas
│   ├── PongEngine.js
│   ├── InvadersEngine.js
│   ├── PacmanEngine.js
│   ├── TetrisEngine.js
│   └── SnakeEngine.js
├── pages/                  # Сторінки роутера
│   ├── HomePage.jsx        # Головна сторінка-музей
│   ├── GamePage.jsx        # Універсальна/окрема сторінка гри з історією
│   ├── AboutPage.jsx       # Сторінка про проєкт та технології
│   └── NotFoundPage.jsx    # Сторінка 404
├── utils/
│   ├── audioService.js     # Синтезатор Web Audio API
│   └── storageService.js   # Допоміжні функції для роботи з localStorage
├── App.jsx                 # Головний компонент із конфігурацією маршрутів (Routes)
└── index.css               # Стилі, імпорт шрифтів, Tailwind директиви
```

### 8. ЕТАПИ РЕАЛІЗАЦІЇ ПРОЄКТУ

| Етап | Зміст робіт | Очікуваний результат |
| :--- | :--- | :--- |
| **Етап 1** | Ініціалізація React-проєкту та налаштування маршрутизації (`react-router-dom`) | Працюючий каркас SPA з перемиканням сторінок без перезавантаження. |
| **Етап 2** | Верстка спільних компонентів (`Navbar`, `Footer`, стилізація під 80-ті, CRT-шар) | Готовий єдиний стиль і дизайн-система сайту. |
| **Етап 3** | Підготовка україномовного історичного контенту для всіх 5 ігор | Текстова база даних із датами, фактами та описом авторів. |
| **Етап 4** | Реалізація ігрових компонентів (Pong, Space Invaders, Snake) на Canvas | 3 робочі ігрові сторінки з коректним очищенням циклу анімації при зміні роуту. |
| **Етап 5** | Реалізація складних ігор (Pac-Man з лабіринтом, Tetris зі стаканом і поворотом) | Повна колекція з 5 діючих інтерактивних аркад. |
| **Етап 6** | Інтеграція Web Audio API, мобільних сенсорних кнопок та зберігання рекордів | Повнофункціональний кросплатформний досвід на смартфонах і ПК. |
| **Етап 7** | Тестування роутів, вичитка українського тексту та підготовка до захисту | Завершений шкільний проєкт, готовий до презентації. |
